# FORA Facebook ad set (Sept 2026)

Three ads, one per service, built to post as a set showing FORA covers a
business at any stage:

- `1-all-in-one.png` — all-in-one field management platform, for new
  construction/trades businesses.
- `2-paper-to-digital.png` — documentation portal, for companies with an
  established paper-based process.
- `3-custom-builds.png` — custom builds, for complex operations off-the-shelf
  software can't handle.

1200x630, dark FORA brand system (`brand.md`), one background photo per ad
sourced free-license from Pexels (no attribution required, verified against
their license terms). Same layout, same "Visit forafieldsolutions.com" CTA
across all three so they read as a set rather than three separate products.
